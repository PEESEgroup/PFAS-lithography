# Figure data connections

The current manuscript figures draw on the following model outputs.

| Figure | Model connection |
|---|---|
| Figure 1 | AI demand, GPU-equivalent manufacturing, wafer/node intensity, PFAS material allocation and waste routing |
| Figure 2 | Agent workflow, mixture composition, substance-specific factors, treatment burdens and residual-emission toxicity |
| Figure 3 | Waste-stream and material-specific management costs |
| Figure 4 | Comparisons of management and technology strategies |
| Supplementary Figure S2 | Detailed substance-level evidence acquisition and toxicity-characterization method |
| Supplementary Figure S10 | Sensitivity of model outputs to selected assumptions |

The main code provides the central calculation chain. Strategy comparisons vary the relevant demand, manufacturing or treatment inputs; figure-specific plotting and the separate sensitivity driver are maintained alongside the study analyses. Figure workbooks will be added separately.
